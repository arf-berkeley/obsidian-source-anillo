The notebook loads these files directly:

- `KRA21_sources.csv` — known source samples, with `Name`, `Group`, and
  elemental concentration columns including `Rb`, `Sr`, and `Zr`.
- `study_samples.csv` — study samples, with `Sample`, `Group`, and elemental
  concentration columns. Bruker column suffixes such as `RbKa1` are normalized
  automatically.

Keep both files in this directory when running the notebook.
